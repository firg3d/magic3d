# Documentația layerling originală

Fișierele din acest folder sunt documentația proiectului [layerling](https://github.com/henmedia/layerling), pe care
Magic3D l-a preluat ca fork pe 31 octombrie 2026, de la versiunea 1.127.0. Sunt păstrate ca referință și pentru
atribuire. Descriu editorul layerling, nu Magic3D, iar unele detalii (imaginile Docker, scripturile de instalare,
adresele) nu se aplică la Magic3D.

| Fișier | Limba |

| [README.de.md](README.de.md) | germană |
| [README.nl.md](README.nl.md) | olandeză |
| [README.ar.md](README.ar.md) | arabă |
| [README.zh-cn.md](README.zh-cn.md) | chineză simplificată |
| [README.zh-tw.md](README.zh-tw.md) | chineză tradițională |

Documentația Magic3D e în [README.md](../../README.md) de la rădăcina proiectului, iar ghidul utilizatorului e pe
[magic3d.ro/ghid](https://magic3d.ro/ghid/index.html).
